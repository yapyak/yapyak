---
title: YAP0046
name: Keyword unknown
severity: error
summary: plural or selectordinal branch is not a CLDR keyword
---

A `plural` or `selectordinal` branch in the source uses a name that is not a CLDR plural keyword and not an exact match like `=1`.

{% diagnostics %}
```ts
t('{count, plural, oen {# item} other {# items}}', { count });  // error: unknown keyword 'oen'
t('{count, plural, one {# item} other {# items}}', { count });  // ok
```
{% /diagnostics %}

Branch names are the CLDR keywords `zero`, `one`, `two`, `few`, `many`, `other`, or an exact match like `=1`. The typed validator reports the same mistake while you type; this diagnostic covers plain JavaScript and code outside the type checker.
