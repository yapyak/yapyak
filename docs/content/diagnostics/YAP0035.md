---
title: YAP0035
name: Unsupported currency
severity: warning
summary: format.number() currency code is unknown to the runtime
---


`format.number(..., { currency: 'XXX' })` is called with a currency code your `Intl` runtime doesn't know. yapyak renders the value as `<value> XXX` instead of failing.

Use a standard ISO 4217 currency code, or verify the runtime's `Intl` polyfill supports the desired code.
