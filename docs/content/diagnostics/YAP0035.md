---
title: YAP0035
name: Unsupported currency
severity: warning
summary: format.number() got a currency code the runtime doesn't know
---


`format.number(..., { currency: 'XXX' })` was called with a currency code your `Intl` runtime doesn't know. yapyak rendered the value as `<value> XXX` instead of failing.

Use a standard ISO 4217 currency code, or verify the runtime's `Intl` polyfill supports the desired code.
