---
title: YAP0002
name: Dynamic template literal
severity: error
summary: t() source is a template literal with interpolation
---


The compiler can't extract a source string built from a template literal.

{% diagnostics %}
```ts
t(`Hi ${name}`);             // error
t('Hi {name}', { name });    // ok
```
{% /diagnostics %}

The source has to be a static string literal. Use a placeholder instead.
