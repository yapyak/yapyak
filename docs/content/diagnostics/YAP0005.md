---
title: YAP0005
name: Extra parameter
severity: error
summary: t() call passes a parameter the source doesn't use
---


The params object has a key the source string doesn't reference.

{% diagnostics %}
```ts
t('Hi', { name: 'A' });          // error: 'name' isn't used
t('Hi {name}', { name: 'A' });   // ok
```
{% /diagnostics %}

Either add `{name}` to the source or remove it from the parameters.
