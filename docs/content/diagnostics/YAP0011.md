---
title: YAP0011
name: Missing in translation
severity: error
summary: placeholder defined in source but absent in translation
---


A placeholder in the source string is missing from the translation.

**Source:**

```ts
t('Hi {name}', { name: 'Alex' });
```

**Translation:**

```json
{
  "Hi {name}": "Hej"
}
```

Add the placeholder to the translation so runtime interpolation works for every locale.
