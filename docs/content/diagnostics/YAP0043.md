---
title: YAP0043
name: Rich-text tag unopened
severity: error
summary: a `</tag>` has no matching opening tag
---


A closing tag has no preceding opening tag.

{% diagnostics %}
```ts
t('terms</link>');                  // error
t('<link>terms</link>');            // ok
```
{% /diagnostics %}

Add an opening tag, or remove the closing tag if it's a stray.
