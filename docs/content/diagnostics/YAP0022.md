---
title: YAP0022
name: Server-side leak risk
severity: warning
summary: getLocale() falls back to the shared module-global locale during SSR
---


`getLocale()` falls back to the shared module-global locale during SSR. Common causes: no SSR adapter, or a response the framework renders without running the adapter, such as a URL that matches no route.

Install the matching [SSR adapter](/guide/getting-started/installation) so each request binds its own locale.
