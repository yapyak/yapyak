---
title: YAP0049
name: Param misspelled
severity: error
summary: params key resembles a placeholder name but does not match it
---

A key in the params object matches no placeholder, and one placeholder is close enough to it to be the intended name.

{% diagnostics %}
```ts
t('You have {count, plural, one {# item} other {# items}}', { conut: 3 });  // error: `conut` does not match `{count}`
t('You have {count, plural, one {# item} other {# items}}', { count: 3 });  // ok
```
{% /diagnostics %}

The candidate is picked with the rule TypeScript uses for its own spelling suggestions, so both tools name the same key. Short names need a closer match than long ones, and a key that resembles nothing reports [YAP0004](/reference/diagnostics/YAP0004) and [YAP0005](/reference/diagnostics/YAP0005) instead.
