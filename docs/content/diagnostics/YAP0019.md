---
title: YAP0019
name: Unused context
severity: error
summary: t.as() context has no other context for the same source
---


`t.as()` only makes sense when the same source is used with another context. If `'Open'` has only one context, the disambiguation is unused.

{% diagnostics %}
```ts
t.as('only', 'Open');   // error: no other context for 'Open' anywhere
t('Open');              // ok
```
{% /diagnostics %}

Drop the `.as()` form when there's no other context to distinguish from.
