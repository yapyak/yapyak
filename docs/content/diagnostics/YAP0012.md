---
title: YAP0012
name: Missing in source
severity: error
summary: placeholder defined in translation but absent in source
---


A placeholder appears in the translation but isn't in the source string. The mirror case of `YAP0011`, usually a hand-edit slip.

**Source:**

```ts
t('Hi');
```

**Translation:**

```json
{
  "Hi": "Hej {name}"
}
```

Either remove the placeholder from the translation, or add it to the source and pass a matching params value.
