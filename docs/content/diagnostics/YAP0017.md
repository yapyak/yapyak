---
title: YAP0017
name: Context not literal
severity: error
summary: t.as() context argument isn't a string literal
---


The first argument to `t.as()` must be a static string literal.

{% diagnostics %}
```ts
t.as(someVariable, 'Open');  // error
t.as('action', 'Open');      // ok
```
{% /diagnostics %}

The compiler needs the context as a literal to associate it with the source string.
