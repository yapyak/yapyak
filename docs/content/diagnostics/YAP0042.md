---
title: YAP0042
name: Rich-text tag mismatched
severity: error
summary: rich-text closing tag does not match the opening
---


A closing tag's name doesn't match the most recent opening tag.

{% diagnostics %}
```ts
t('<link>terms</bold>');     // error
t('<link>terms</link>');     // ok
```
{% /diagnostics %}

Either fix the closing tag to match the opening, or close the inner tag first if you meant to nest them.
