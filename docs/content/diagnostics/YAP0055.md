---
title: YAP0055
name: Module scope call
severity: warning
summary: t() evaluates once when the module loads and its result never updates
---


A `t()` call sits at module scope, so it evaluates once when the module loads. The result never updates when the active locale changes, and on the server it is shared across requests.

{% diagnostics %}
```ts
const title = t('Settings');  // error
function Header() {
  return t('Settings');       // ok
}
```
{% /diagnostics %}

Call `t()` inside the component or function where the text is used. A call inside a function reads the active locale each time it runs.
