---
title: YAP0052
name: Invalid placeholder name
severity: error
summary: ICU forbids whitespace and punctuation in argument names
---


A placeholder name holds a character ICU does not allow, or starts with a digit.

{% diagnostics %}
```ts
t('Hi {first name}', { 'first name': name });  // error: space in the name
t('Hi {firstName}', { firstName: name });      // ok
```
{% /diagnostics %}

ICU MessageFormat excludes whitespace and punctuation from argument names, so `{first name}`, `{first-name}` and `{first.name}` are all rejected. Names take letters, digits, and underscores, and start with a letter or underscore. Letters outside ASCII are fine, so `{förnamn}` and `{名前}` both work.
