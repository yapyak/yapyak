---
title: YAP0001
name: No source
severity: error
summary: t() called without a source argument
---


`t()` or `t.as()` was called without a source string.

{% diagnostics %}
```ts
t();                            // error
t('Save changes');              // ok

t.as('action');                 // error
t.as('action', 'Save changes'); // ok
```
{% /diagnostics %}

Pass the source string as the first argument (second for `t.as()`).
