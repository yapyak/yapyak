---
title: YAP0013
name: Invalid shape
severity: error
summary: locale entry isn't a string or context-keyed object
---


A locale entry doesn't match the expected shape. Each entry must be a string or a context-keyed object of strings.

**Invalid:**

```json
{
  "src/a.tsx": {
    "Save": 42
  }
}
```

**Valid:**

```json
{
  "src/a.tsx": {
    "Save": "Spara",
    "Open": { "action": "Öppna", "status": "Öppen" }
  }
}
```

Fix the entry by hand, or regenerate it via `yapyak translate`.
