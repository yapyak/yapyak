---
title: YAP0036
name: Unsupported unit
severity: warning
summary: format.number() unit is unknown to the runtime
---


`format.number(..., { unit: '...' })` is called with a unit your `Intl` runtime doesn't know. yapyak renders the value as `<value> <unit>` instead of failing.

Use a standard ECMA-402 sanctioned unit, or verify the runtime's `Intl` polyfill supports the desired unit.
