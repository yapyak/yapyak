---
title: YAP0036
name: Unsupported unit
severity: warning
summary: format.number() got a unit the runtime doesn't know
---


`format.number(..., { unit: '...' })` was called with a unit your `Intl` runtime doesn't know. yapyak rendered the value as `<value> <unit>` instead of failing.

Use a standard ECMA-402 sanctioned unit, or verify the runtime's `Intl` polyfill supports the desired unit.
