---
title: YAP0008
name: Missing `other` branch
severity: error
summary: plural, selectordinal, or select placeholder lacks an `other` fallback
---


An ICU `plural`, `selectordinal`, or `select` placeholder is missing the required `other` branch.

{% diagnostics %}
```ts
t('{count, plural, one {one}}', { count });                       // error: missing 'other'
t('{count, plural, one {one} other {many}}', { count });          // ok
```
{% /diagnostics %}

`plural`, `selectordinal`, and `select` all require an `other` fallback.
