---
title: YAP0038
name: Missing branch in target
severity: error
summary: translation omits a plural or select branch the source defines
---


A translation omits a plural or select branch that the source defines.

**Source:**

```ts
t('{count, plural, one {one} few {few} other {many}}');
```

**Translation:**

```json
{
  "{count, plural, one {one} few {few} other {many}}": "{count, plural, one {ett} other {många}}"
}
```

Add the missing branch to the translation. Some locales need branches the source doesn't have (Slavic languages, Arabic) and vice versa; the compiler flags omissions in both directions.
