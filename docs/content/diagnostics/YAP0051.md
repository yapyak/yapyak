---
title: YAP0051
name: Misspelled in translation
severity: error
summary: translation holds a placeholder that resembles one in the source
---

A placeholder in the translation matches no placeholder in the source, and one source placeholder is close enough to it to be the intended name.

**Source:**

```ts
t('You have {count} messages', { count: 3 });
```

**Translation:**

```json
{
  "You have {count} messages": "Du har {conut} meddelanden"
}
```

Rename the placeholder in the locale file. The candidate is picked with the rule TypeScript uses for its own spelling suggestions, and a placeholder that resembles nothing reports [YAP0011](/reference/diagnostics/YAP0011) and [YAP0012](/reference/diagnostics/YAP0012) instead.
