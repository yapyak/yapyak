---
title: YAP0041
name: Rich-text tag unclosed
severity: error
summary: rich-text tag has no matching closing tag
---


An opening tag in the source has no matching closing tag.

{% diagnostics %}
```ts
t('Read <link>terms');             // error
t('Read <link>terms</link>');      // ok
```
{% /diagnostics %}

Close the tag with `</link>`, or use a void tag `<link/>` if it has no content.
