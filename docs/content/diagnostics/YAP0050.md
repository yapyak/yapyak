---
title: YAP0050
name: Translation malformed
severity: error
summary: translation holds ICU syntax that does not parse
---

The translation of a source string has broken ICU syntax, so its placeholders cannot be read.

**Source:**

```ts
t('Hi {name}', { name: 'Alex' });
```

**Translation:**

```json
{
  "Hi {name}": "Hej {name"
}
```

Fix the syntax in the locale file. While the translation does not parse, its placeholders stay unknown, so the placeholder checks are skipped for that entry rather than reporting every placeholder as missing.
