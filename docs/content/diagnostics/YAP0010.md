---
title: YAP0010
name: Kind mismatch
severity: error
summary: translation changes a placeholder's format kind
---


A translation changes a placeholder's format kind (e.g., `plural` to `select`). The structure must match between source and translation.

**Source:**

```ts
t('{count, plural, one {one} other {other}}');
```

**Translation:**

```json
{
  "{count, plural, one {one} other {other}}": "{count, select, one {one} other {other}}"
}
```

A `plural` placeholder in the source must remain `plural` in every translation. Same rule for `select` and `selectordinal`.
