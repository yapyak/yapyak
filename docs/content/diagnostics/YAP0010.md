# `YAP0010` — Kind mismatch

Source:

```ts
t('{count, plural, one {one} other {other}}');
```

Translation:

```json
{
  "{count, plural, one {one} other {other}}": "{count, select, ...}"
}
```

A translation can't change a placeholder's format from `plural` to `select`. The structure has to match.
