---
title: YAP0018
name: Mixed usage
severity: error
summary: same source uses both t() and t.as() in one file
---


A source string can't be used with both `t()` and `t.as()` in the same file.

{% diagnostics %}
```ts
t('Open');                  // error: also used with t.as
t.as('action', 'Open');     // error: also used with bare t
```
{% /diagnostics %}

Pick one form per source. If you need to disambiguate, use `t.as()` for every occurrence.
