---
title: YAP0048
name: Parse error
severity: error
summary: a framework processor reports a syntax problem in the source file
---

A framework processor's parser reports an error in the source file, so its `t()` calls cannot be extracted.

{% diagnostics %}
```astro
---
import { t } from 'yapyak';
---
<p>{t('Hello')</p>   // error: the expression never closes
<p>{t('Hello')}</p>  // ok
```
{% /diagnostics %}

The message carries the parser's own description and the range points at the reported location. yapyak's Astro processor surfaces the Astro compiler's parse errors this way.
