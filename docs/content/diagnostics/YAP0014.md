---
title: YAP0014
name: Unsafe path
severity: error
summary: file-path key contains `..`, a Windows separator, or is absolute
---


A locale file-path key contains `..`, a Windows-style backslash, or is absolute. Path keys are normally derived from source-file locations by the extractor, so this almost always means something other than yapyak wrote the entry.

Common causes: an imported locale file from another tool, a hand-edited key, or a misconfigured CI step that rewrote paths. Find the entry in the locale JSON, identify how it got there, and remove or rewrite it as a forward-slash relative path inside the project.
