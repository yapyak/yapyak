---
title: YAP0044
name: Rich-text tag name missing
severity: error
summary: rich-text tag has no name
---


A tag has empty brackets and no name.

{% diagnostics %}
```ts
t('This example uses<> cool');         // error
t('This example uses <link>cool</link>');  // ok
```
{% /diagnostics %}

Add a name like `<link>`, or remove the brackets if you meant literal text.
