---
title: YAP0006
name: Dynamic parameters
severity: error
summary: t() params argument is a variable, not an inline object
---


The compiler can't read params unless they're an inline object literal.

{% diagnostics %}
```ts
t('Hi {name}', params);         // error: can't be statically verified
t('Hi {name}', { name: 'A' });  // ok
```
{% /diagnostics %}

Pass the params object inline so the compiler can read it.
