---
title: YAP0053
name: Entry unused
severity: warning
summary: locale file holds a translation whose source string is no longer used
---


A locale file holds a translation for a source string that no `t()` call in that file uses any more.

**Source code:**

```ts
t('Hello');
```

**Translation:**

```json
{
  "src/a.tsx": {
    "Cancel": "Avbryt",
    "Hello": "Hej"
  }
}
```

`Cancel` is left over from a `t()` call that was edited or removed. The dev server moves such entries into the orphan cache on the next save, so this usually means the file was changed by hand or the dev server has not run since. Delete the entry, or restore the `t()` call that used it.

The check only runs for source files the compiler could read. A file with a syntax error contributes no messages, so its translations are never reported as unused while it is broken.
