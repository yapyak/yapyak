---
title: YAP0003
name: Empty source
severity: error
summary: t() source is an empty string
---


`t()` was called with an empty string as the source.

{% diagnostics %}
```ts
t('');              // error
t('Save changes');  // ok
```
{% /diagnostics %}

Empty strings can't be translation keys. If you genuinely want an empty render, return `''` directly.
