---
title: YAP0020
name: Captured chain
severity: error
summary: t.as() or t.in() chain stored in a variable
---


The chain forms `t.as(...)` and `t.in(...)` must be called inline so the compiler can extract the source.

{% diagnostics %}
```ts
const tr = t.as('action');         // error
tr('Open');                        // error
t.as('action', 'Open');            // ok
```
{% /diagnostics %}

Inline calls let the compiler walk the chain and pair the context with the source.
