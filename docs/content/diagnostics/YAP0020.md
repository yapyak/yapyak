---
title: YAP0020
name: Captured chain
severity: error
summary: t.as() or t.in() chain stored in a variable
---


{% diagnostics %}
const tr = t.as('action');  // no
tr('Open');                 // no
{% /diagnostics %}

The chain forms (`t.as(...)`, `t.in(...)`) have to be used inline — the compiler can't extract a source through a stored chain.
