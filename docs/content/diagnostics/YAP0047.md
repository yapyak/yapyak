---
title: YAP0047
name: Unreadable locale file
severity: warning
summary: locale file exists but the filesystem denies the read
---

A locale file is not readable. The file exists, but the filesystem denies the read, usually because of file permissions or an exhausted open-file limit.

The dev server keeps the translations it already loaded and skips this file. Check the file permissions and the open-file limit, then restart the dev server.
