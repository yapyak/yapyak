---
title: YAP0045
name: Branch unknown
severity: error
summary: translation plural branch is not a category of the target locale
---

A `plural` or `selectordinal` branch in the translation uses a name that is neither a plural category of the target locale nor an exact match like `=1`.

**Source:**

```ts
t('You have {count, plural, one {# message} other {# messages}}', { count: 1 });
```

**Translation:**

```json
{
  "You have {count, plural, one {# message} other {# messages}}": "Du har {count, plural, en {# meddelande} other {# meddelanden}}"
}
```

Branch names are CLDR category keywords, not translated words. The `en` branch never matches, so `count: 1` renders the `other` branch. Rename the branch to a category of the target locale, here `one`.
