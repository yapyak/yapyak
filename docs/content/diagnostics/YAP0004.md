---
title: YAP0004
name: Missing parameter
severity: error
summary: t() call is missing a placeholder parameter
---


{% diagnostics %}
t('Hi {name}', {});            // error: missing 'name'
t('Hi {name}', { user: 'A' }); // error: missing 'name', extra 'user'
{% /diagnostics %}

Add the key to the params object.
