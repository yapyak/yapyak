# Security

> Vulnerabilities should be reported privately, not in public issues.

## Reporting

Open a [private vulnerability report](https://github.com/<owner>/<repo>/security/advisories/new) on GitHub. Do not file a public issue.

We aim to acknowledge within 72 hours and provide a status update within 7 days. Coordinated disclosure follows once a fix is ready or the issue is determined out-of-scope.

## Supported versions

The latest released version of each `@yapyak/*` package is supported. Older versions receive security fixes at the maintainers' discretion.

## Scope

In scope: vulnerabilities in published packages (`yapyak`, `@yapyak/*`).
Out of scope: vulnerabilities in third-party dependencies (report those upstream).
