# @yapyak/cli

> Node-only

CLI for yapyak. Installs the `yapyak` binary.

## Installation

```bash
npm install @yapyak/cli
# or
pnpm add @yapyak/cli
```

## Usage

```bash
npx yapyak add fr
npx yapyak translate
npx yapyak status
```
